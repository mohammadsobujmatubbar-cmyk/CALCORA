# CALCORA

Smart Calculator & Digital Ledger

Calculate • Write • Remember

## Planned Features
- Smart calculator and calculation history
- Multiple digital notebooks
- Stylus and finger handwriting
- Eraser, Undo and Redo
- Automatic saving
- PDF export
- Backup and Restore
- Notebook lock

## Technology
- Kotlin
- Jetpack Compose
- Room Database (planned)
- MVVM + Repository (planned)
- GitHub Actions cloud builds

Package: `com.calcora.app`
